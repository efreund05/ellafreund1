# EF Creative Website

Static portfolio website for Ella Freund and EF Creative, built with HTML, CSS, and a small amount of vanilla JavaScript for easy GitHub Pages hosting.

## Structure

- `index.html`
- `about.html`
- `services.html`
- `contact.html`
- `faq.html`
- `support.html`
- `resources.html`
- `assets/`
- `css/style.css`
- `js/main.js`

## Editing

- Replace the SVG placeholders in `assets/` with your own Canva exports or photos.
- Update page copy directly in the HTML files.
- Adjust colors, spacing, and layout in `css/style.css`.

## GitHub Pages

This site can be published directly from the repository root using GitHub Pages.
